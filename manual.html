1. Qué es NEXO (y qué no es)

⭐ Cómo se usa NEXO NEXO no se instala, no es una app de tu teléfono y no es un contacto de WhatsApp. Solo existe como servicio web con la página /editor y una API. Se opera de dos formas: (a) desde el chat de Muse con comandos en lenguaje natural («extrae mis fotos de facebook de esta semana»), o (b) directo en el navegador (/editor, /api/…). No hay nada que descargar ni ningún número al que escribirle.

NEXO es tu hub personal de extracción de contenidos: extrae fotos, posts y videos de tus propias cuentas de Facebook e Instagram (vía la API oficial de Meta), o de exportaciones de chats de WhatsApp que subes manualmente, los normaliza en paquetes estándar y los deja listos para curar y enviar en lote a tus apps.

Qué NO es / qué NO hace

  • No es un bot de WhatsApp. No tiene número, no recibe tus mensajes, no aparece en tus chats. La captura por WhatsApp la hace el Asistente Puente (+1 555-153-9713).
  • No modifica el Asistente Puente en producción. Son servicios separados, con repos y deploys separados.
  • No escribe recuerdos solo. Todo lo que sale de NEXO hacia Legado Vivo o Taller entra como borrador; tú decides qué se envía y lo completas allá.
  • No accede a cuentas ajenas. Solo tus propias cuentas de Facebook e Instagram, con tokens que tú autorizas.
  • No da acceso a tus apps privadas de Muse (Momentos, Recetas, etc.). Esas se siguen usando desde Muse; NEXO las alimenta (prepara payloads para Momentos, manda borradores a Legado Vivo e ideas a Taller).

El paquete estándar

Cada contenido extraído se convierte en un paquete: {package_id, source, author, created_at, text, media[], metadata}. NEXO lo enriquece (categoría, resumen, etiquetas, dedupe_key para no guardar dos veces lo mismo) y lo guarda con estado listo hasta que lo cures y envíes.

El ecosistema tiene dos puertas al mismo destino (Legado Vivo). No compiten; cada una es buena en lo suyo:

💬

Puerta 1 — Asistente Puente

Captura en el momento, uno a la vez.
Foto + nota de voz por WhatsApp → borrador en Legado Vivo.

Para fotos sueltas del día a día.

🗂️

Puerta 2 — NEXO

Extracción y curaduría en lote.
Facebook / Instagram / export de WhatsApp → paquetes → editor → envío en lote.

🏠 Destino: Legado Vivo (borradores «Pendiente de completar») · Taller (ideas)

4. Editor de curaduría

  1. Abre https://tu-servicio.onrender.com/editor: verás tus paquetes en tarjetas con miniatura, fuente, fecha, autor y estado.
  2. Filtra por fuente (Facebook/Instagram/WhatsApp), estado o texto; selecciona varios con un clic (o el checkbox).
  3. Retoca cada uno con ✏️: ajusta el título y el texto tal como quieres que lleguen a Legado Vivo (los retoques se guardan en el paquete).
  4. Pulsa «Enviar a Legado Vivo»: confirma y el lote viaja como borradores («Pendiente de completar»). Verás ✓ por cada enviado y ✗ con el motivo si alguno falla. Hasta 50 paquetes por llamada.

Estados

  • listo — paquete curable, aún no enviado.
  • entregado_legado — enviado a Legado Vivo como borrador.
  • entregado_taller — enviado a Taller como idea (llega por API; ver sección 7).
Nota explícita: el botón del editor está programado para enviar solo a Legado Vivo. Para enviar paquetes a Taller usa la API: POST /api/packages/:id/deliver con { "app": "taller" }, o POST /api/packages/deliver-batch con "app": "taller".

La entrega es idempotente: cada paquete viaja con draftId: nexo-<package_id>, así que reenviar no duplica borradores.

5. Importar un chat de WhatsApp

  1. En tu iPhone: abre el chat → nombre del chat → Exportar chat → Sin archivos → envíate el .txt.
  2. POST /api/import/whatsapp-export con { "text": "<contenido del .txt>", "chatName": "<nombre del chat>" } → crea un paquete por mensaje.
  3. Los paquetes aparecen en el /editor listos para curar y enviar.

Formatos aceptados

iPhone en inglés (AM/PM)[9/29/26, 1:23:28 PM] Nombre: mensaje — convierte 12h→24h y detecta mes/día automáticamente
Android29/9/26, 13:23 - Nombre: mensaje

Los mensajes que son solo foto/video (<imagen omitida>, <video omitido>, <Mensaje de album>) se marcan con has_media. Reimportar el mismo .txt no duplica (cada mensaje conserva su source_id).

Límite honesto: NEXO no une las fotos de tu carrete con sus placeholders del .txt. La exportación sin archivos solo trae texto; las fotos reales viajan por el otro carril (Asistente Puente por WhatsApp, o se suben directo en Legado Vivo). Este importador sirve para chats donde el texto es el recuerdo (historias, anécdotas, noticias familiares).

6. Búsqueda semántica y Q&A

Requiere OPENAI_API_KEY en Render (sin ella, estas rutas responden 503 y nada más cambia).

  • Cada paquete se vectoriza solo al guardarse (OpenAI text-embedding-3-small, pgvector en PostgreSQL). Si activas la key después, vectoriza los pendientes con POST /api/embeddings/backfill (lotes de 20).
  • Busca por significado: GET /api/search?q=atardecer en la playa&limit=8 → paquetes ordenados por similitud, con score, extracto, fuente y fecha.
  • Pregunta en lenguaje natural: POST /api/qa con {"question": "¿cuándo fuimos a la playa con Dante?"} → respuesta breve que usa solo tus recuerdos y cita cada dato como [1], [2] (con package_id, fuente, fecha y enlace). Si no hay nada, lo dice en vez de inventar.

7. Puente con Taller

NEXO habla con tu app Taller (estudio creativo) vía su API de puente (/api/bridge/* con header x-bridge-key). Requiere TALLER_URL + TALLER_BRIDGE_KEY en Render; sin ellas el adaptador queda inactivo sin romper nada (la raíz / reporta adaptador_taller).

  • POST /api/packages/:id/deliver con { "app": "taller" } → crea la idea en Taller (idempotente por requestKey determinista); el paquete queda entregado_taller.
  • POST /api/packages/deliver-batch con "app": "taller" → lo mismo en lote (hasta 50).
  • GET /api/taller/status → salud del puente.
  • POST /api/taller/ideas con { title, hobby?, body? } → crear idea.
  • POST /api/taller/chat con { message, mode? } → chatear con el asistente de Taller (modos chat/review/plan; solo texto).

8. Webhook de WhatsApp multi-mensaje

Infraestructura opt-in, hoy inactiva: esto no es «NEXO en WhatsApp». Es un webhook técnico opcional para un caso futuro (cuando Meta apruebe la verificación del negocio). Sin WHATSAPP_TOKEN, PHONE_NUMBER_ID, VERIFY_TOKEN y APP_SECRET, el webhook rechaza los eventos y NEXO funciona igual. Se configuraría con una app de Meta aparte de la del Asistente Puente.

Si algún día se activa: agrupa mensajes consecutivos del mismo remitente en lotes (se cierra con 30 s de pausa o al tope de 3 min), detecta triggers (photo_relatos, album_caption, multi_photo_album, audio_note…), las fotos seguidas se juntan en un álbum para Momentos y cada nota de voz queda como transcripción separada (Whisper si hay OPENAI_API_KEY).

9. Renovación automática del token de Facebook

El token de usuario de Facebook vive 60 días. Si configuras FACEBOOK_APP_ID y FACEBOOK_APP_SECRET (de tu app «NEXO Personal» en Meta for Developers → Configuración → Información básica), NEXO verifica la vigencia al arrancar y cada 24 h, y renueva el token solo cuando vence dentro de 7 días (FB_TOKEN_REFRESH_MARGIN_DAYS).

  • Consulta el estado en GET /api/facebook/token (válido, días restantes, fuente; nunca muestra el valor del token).
  • Para forzar una renovación: POST /api/facebook/token/refresh.

10. JEV — decisiones con IA

Con TYPESAFE_API_KEY (alias JEV_API_KEY), JEV (TypeSafe AI) actúa como cerebro de decisiones rápidas por paquete. JEV no genera texto: no escribe resúmenes ni etiquetas.

  • choice → categoría temática con confianza (si ≥ 0.75 reemplaza la heurística).
  • score → puntaje de relevancia (0–100).
  • noul → puertas binarias: ¿duplicado probable? ¿entrega segura?

Confianza baja → revisión humana, no automatización: el paquete queda marcado en metadata.revision_humana con el motivo. Sin key, o si el servicio falla, el paquete conserva sus heurísticas locales y sigue su curso.

1. What NEXO is (and isn't)

⭐ How you use NEXO NEXO is not installed, is not a phone app, and is not a WhatsApp contact. It only exists as a web service with the /editor page and an API. You operate it two ways: (a) from the Muse chat with natural-language commands ("extract my facebook photos from this week"), or (b) directly in the browser (/editor, /api/…). Nothing to download, no number to message.

NEXO is your personal content-extraction hub: it pulls photos, posts and videos from your own Facebook and Instagram accounts (via Meta's official API), or from WhatsApp chat exports you upload manually, normalizes them into standard packages, and gets them ready for batch curation and delivery to your apps.

What it is NOT / does NOT do

  • Not a WhatsApp bot. No number, doesn't receive your messages, doesn't appear in your chats. WhatsApp capture is done by the Asistente Puente (+1 555-153-9713).
  • Doesn't touch the production Asistente Puente. Separate services, separate repos and deploys.
  • Never writes memories on its own. Everything leaving NEXO for Legado Vivo or Taller enters as a draft; you choose what gets sent and finish it there.
  • No access to other people's accounts. Only your own Facebook and Instagram accounts, with tokens you authorize.
  • Doesn't give access to your private Muse apps (Momentos, Recetas, etc.). Those are still used from Muse; NEXO feeds them (prepares payloads for Momentos, sends drafts to Legado Vivo and ideas to Taller).

The standard package

Each extracted item becomes a package: {package_id, source, author, created_at, text, media[], metadata}. NEXO enriches it (category, summary, tags, dedupe_key so nothing is stored twice) and keeps it as listo until you curate and deliver it.

2. The two doors: Asistente Puente vs NEXO

The ecosystem has two doors to the same destination (Legado Vivo). They don't compete; each is good at its own thing:

💬

Door 1 — Asistente Puente

Capture in the moment, one at a time.
Photo + voice note over WhatsApp → draft in Legado Vivo.

For one-off daily photos.

🗂️

Door 2 — NEXO

Batch extraction and curation.
Facebook / Instagram / WhatsApp export → packages → editor → batch delivery.

For volume: weeks of posts, whole chats.

🏠 Destination: Legado Vivo ("Pendiente de completar" drafts) · Taller (ideas)
Important: there is no third lane where you pass photos through the Muse chat and NEXO builds packages with those photos. Photos travel through Door 1 (Asistente Puente) or are uploaded directly on the Legado Vivo website.

4. Curation editor

  1. Open https://your-service.onrender.com/editor: your packages appear as cards with thumbnail, source, date, author and status.
  2. Filter by source (Facebook/Instagram/WhatsApp), status or text; select several with a click (or the checkbox).
  3. Touch up each one with ✏️: adjust the title and text exactly as you want them to arrive in Legado Vivo (touch-ups are saved on the package).
  4. Press "Enviar a Legado Vivo": confirm and the batch travels as drafts ("Pendiente de completar"). You'll see ✓ per delivered item and ✗ with the reason if any fails. Up to 50 packages per call.

Statuses

  • listo — curatable package, not yet delivered.
  • entregado_legado — delivered to Legado Vivo as a draft.
  • entregado_taller — delivered to Taller as an idea (arrives via API; see section 7).
Explicit note: the editor's button is hardwired to deliver only to Legado Vivo. To deliver packages to Taller, use the API: POST /api/packages/:id/deliver with { "app": "taller" }, or POST /api/packages/deliver-batch with "app": "taller".

Delivery is idempotent: each package travels with draftId: nexo-<package_id>, so resending never duplicates drafts.

  2. POST /api/import/whatsapp-export with { "text": "<.txt contents>", "chatName": "<chat name>" } → creates one package per message.
  3. Packages show up in /editor, ready to curate and deliver.

6. Semantic search & Q&A

Requires OPENAI_API_KEY on Render (without it, these routes answer 503 and nothing else changes).

  • Each package is auto-vectorized on save (OpenAI text-embedding-3-small, pgvector on PostgreSQL). If you enable the key later, backfill pending ones with POST /api/embeddings/backfill (batches of 20).
  • Search by meaning: GET /api/search?q=sunset at the beach&limit=8 → packages ordered by similarity, with score, extracto, source and date.
  • Ask in natural language: POST /api/qa with {"question": "when did we go to the beach with Dante?"} → a short answer using only your memories, citing each fact as [1], [2] (with package_id, source, date and link). If there's nothing, it says so instead of inventing.

7. Taller bridge

NEXO talks to your Taller app (creative studio) through its bridge API (/api/bridge/* with the x-bridge-key header). Requires TALLER_URL + TALLER_BRIDGE_KEY on Render; without them the adapter stays inactive without breaking anything (the / root reports adaptador_taller).

  • POST /api/packages/:id/deliver with { "app": "taller" } → creates the idea in Taller (idempotent via deterministic requestKey); the package becomes entregado_taller.
  • POST /api/packages/deliver-batch with "app": "taller" → same, in batch (up to 50).
  • GET /api/taller/status → bridge health.
  • POST /api/taller/ideas with { title, hobby?, body? } → create an idea.
  • POST /api/taller/chat with { message, mode? } → chat with Taller's assistant (modes chat/review/plan; text only).

8. Multi-message WhatsApp webhook

Opt-in infrastructure, currently inactive: this is not "NEXO on WhatsApp". It's an optional technical webhook for a future scenario (once Meta approves business verification). Without WHATSAPP_TOKEN, PHONE_NUMBER_ID, VERIFY_TOKEN and APP_SECRET, the webhook rejects events and NEXO works the same. It would be configured on a Meta app separate from the Asistente Puente's.

If ever enabled: it groups consecutive messages from the same sender into batches (flushed after a 30 s pause or a 3 min cap), detects triggers (photo_relatos, album_caption, multi_photo_album, audio_note…), consecutive photos are bundled into an album for Momentos, and each voice note becomes a separate transcription (Whisper if OPENAI_API_KEY is set).

9. Automatic Facebook token renewal

The Facebook user token lives 60 days. If you set FACEBOOK_APP_ID and FACEBOOK_APP_SECRET (from your "NEXO Personal" app in Meta for Developers → Settings → Basic), NEXO checks validity at boot and every 24 h, and renews the token by itself when it expires within 7 days (FB_TOKEN_REFRESH_MARGIN_DAYS).

  • Check status at GET /api/facebook/token (valid, days remaining, source; it never shows the token value).
  • To force a renewal: POST /api/facebook/token/refresh.

10. JEV — AI decisions

With TYPESAFE_API_KEY (alias JEV_API_KEY), JEV (TypeSafe AI) acts as the fast-decision brain per package. JEV doesn't generate text: it writes no summaries or tags.

  • choice → topic category with confidence (replaces the heuristic if ≥ 0.75).
  • score → relevance score (0–100).
  • noul → binary gates: probable duplicate? safe delivery?

Low confidence → human review, not automation: the package is flagged in metadata.revision_humana with the reason. Without a key, or if the service fails, the package keeps its local heuristics and continues normally.

12. Testing & troubleshooting

  • npm test → 31 tests (unit + E2E in DRY_RUN, no real credentials).
  • node test-all.js → 51 tests (webhook, token-refresh, embeddings, multi-message batching E2E).
  • Broken deploy after uploading the ZIP: check the files are flat at the repo root (no code subfolders) and package.json is NEXO's. Read the Render log: Cannot find module is almost always a misplaced file.
  • Root doesn't show the new version: run Manual Deploy → Deploy latest commit on Render and wait for it to finish.
  • WhatsApp import returns 0 messages: check the .txt was exported without media and the format is iOS or Android (see section 5).
  • Batch delivery to Legado Vivo fails: verify LEGADO_VIVO_URL, BRIDGE_API_KEY (same as on Railway) and LEGADO_FAMILY_ID on Render.
  • Packages can't be deleted yet from the editor: simply don't select them for delivery.

13. Honest limits

  • WhatsApp has no official API for reading your personal chats. The way in is the manual chat export.
  • Only your own Facebook and Instagram accounts, and what the official API allows. Instagram requires a business/creator account.
  • The WhatsApp importer does not join photos with placeholders (see section 5).
  • The editor button only delivers to Legado Vivo; Taller delivery goes through the API (see section 4).
  • Momentos exposes no public API: albums are imported from the Muse chat.
  • Tokens are never pasted into chats or code: they live only as environment variables on Render.
